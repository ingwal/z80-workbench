    I/O ports

    $
    Click the terminal and type. Keys wait in a buffer until the program reads them.
    T-statePortValueDecChar

    Port $00 (status): bit 0 = a key is waiting, bit 1 = ready to print. Port $01 (data): IN reads the next key, OUT prints a character. 13 starts a new line, 8 erases.

    Keys: S step, O step over (runs a CALL, RST, DJNZ or block instruction to completion), G run or stop, Esc stop. Drop a raw binary or an Intel HEX file anywhere on the page. Raw binaries load at the address in the toolbar; Intel HEX files load at the addresses inside them. Running stops at HALT and at breakpoints. No interrupts are generated.
